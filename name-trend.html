How Has My Name Changed in Popularity?

Research question

How has the popularity of the selected name changed during the ten most recent years available in the U.S. Social Security Administration baby-name data?

Data

This analysis uses baby-name records from the U.S. Social Security Administration. Each row contains a name, sex, year, and number of babies given that name.

This document is using the packaged babynames mirror. The mirror is an older copy, so if the SSA download is available it will automatically be used instead.

Prepare the data

The analysis uses the ten latest complete years in the dataset. Rank is calculated separately for each year and sex because the SSA data reports names by sex.

Patterns to discuss

Use the graphs and table to answer these questions:

  • Did the number of babies given this name increase, decrease, or stay fairly stable?
  • Did the name’s rank change in the same direction as its number of births?
  • Does the name appear for more than one sex? If so, is one trend different from the other?
  • Were there any sudden increases or decreases?
  • Did the name become more or less common relative to all births?
  • What cultural, historical, or generational explanation might help explain the pattern?
